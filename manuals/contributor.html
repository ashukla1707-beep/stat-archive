Contributor Manual

Filing and maintaining study material · Updated August 2026

Who this manual is for: Approved contributors who add and maintain archive content.

Contributors have all Reader features plus controlled archive-maintenance permissions. This manual focuses on safe filing, editing and recent-entry cleanup.

1. Contributor Access

  1. Choose the correct M.Sc / B.Sc level before signing in.
  2. Tap Sign in and choose Contributor.
  3. Enter the contributor passcode for the selected level.
  4. On supported Android app builds, you can choose to remember the passcode securely on that device.
  5. After successful sign-in, acknowledge the contributor notice before filing material.
Security: Contributor passcodes are level-specific. Do not share them publicly or place them inside documents, screenshots or source code.

2. File a New Entry

  1. Tap + File a new entry.
  2. Choose the correct Subject and Type.
  3. Enter the required year when the selected type requires it; add title/subtitle information where the form requests it.
  4. Tap Choose file and select a PDF. In the Android app, the native picker returns the selected PDF to the form.
  5. Confirm that the filename appears beside Choose file before tapping Add to archive.
  6. Tap Add to archive and wait for the filing operation to finish before closing the form.

3. File Rules and Size Limits

Entry typeNormal upload limit
Previous Year Question1 MB
Mid-Term Question1 MB
Notes20 MB
Book20 MB
Others10 MB
  • Normal uploaded files must be PDF files.
  • If a file exceeds its normal limit, upload it to Google Drive, make the sharing link viewable, and use the large-file Drive-link option in the filing form.
  • Drive-linked entries show Open in Drive instead of the normal local Preview/Download actions.

4. Add and Rename Subjects

  • Contributor subject controls apply to the currently selected M.Sc/B.Sc level.
  • Add a new subject only after checking spelling and naming consistency.
  • Rename a subject when a correction is needed.
  • Subject deletion is intentionally not available, so avoid creating duplicate or temporary subjects.

5. Edit an Entry

  1. Open the entry management action available while signed in.
  2. Update subject, type, year, title or other editable metadata as needed.
  3. If replacing the PDF, choose a new file. Leaving the replacement-file field empty keeps the current file.
  4. If switching to a Google Drive link, use the corresponding Drive-link field and verify the sharing permission.
  5. Save and then verify the entry from the normal Reader view.

6. Delete an Entry

  • Contributors can delete only their 3 most recently uploaded entries.
  • Older entries require Admin permission.
  • Read the confirmation dialog carefully before deleting. Deletion affects the online archive, unlike Offline Library Remove, which deletes only a device-local copy.
Contributor boundary: If the task involves an older entry, account/passcode configuration, APK release, website deployment, or changing system behaviour, hand it to the Admin.

8. Common Problems

SymptomLikely fix
Choose file opens but form still says No file chosenUse the current Android app version; the app must return the chooser result to the WebView.
Add to archive says choose a fileConfirm the selected filename is visible before submitting.
File too largeUse the Drive-link option or reduce the file size.
Cannot delete an older entryAsk an Admin; contributor deletion is limited to the newest 3 uploads.
Wrong subject listSwitch to the correct M.Sc/B.Sc level.
